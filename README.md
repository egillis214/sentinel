# Sentinel

Situational-awareness dashboard firmware for BYO ESP32 display hardware.

## The tiers (claims never cross tiers)
- **Dashboard — available now.** WiFi-connected situational display. Free/open firmware for BYO CYD-class ESP32 boards (CYD = "Cheap Yellow Device", ~$20 ESP32 dev-board class hardware such as the ESP32-2432S028).
- **Tag — future.** One-button passive accountability (OK / not-OK + heartbeat) over license-free LoRa. Not messaging, not tracking, not a radio replacement.
- **Base — future.** LoRa-to-WiFi bridge feeding dashboards. Tag-to-base link is a custom direct LoRa star protocol.
